# Reproducibility materials

Code and supporting files for *Accelerating the Discovery of High-Performance Multi-component Thermodynamic Hydrate Inhibitors via Bayesian Optimization with Molecular Insights into Synergistic Mechanisms*.

## Contents

- `01_code`: model training and evaluation code
- `02_source_references_and_curated_data`: source data
- `03_split_indices`: training, test, and additional-validation indices
- `04_trained_models`: trained model archive
- `05_bayesian_optimization`: formulation-optimization code
- `06_md_input_files`: LAMMPS input files for the five simulated systems
